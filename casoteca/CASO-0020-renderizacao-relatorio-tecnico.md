# CASO-0020 — Renderização do Relatório Técnico

O caso transforma o relatório técnico gerado no `CASO-0019` em:

- texto simples UTF-8;
- Markdown estruturado;
- HTML semântico.

As três representações preservam a ordem das doze seções, a referência
processual e o conteúdo técnico, sem realizar cálculos.
