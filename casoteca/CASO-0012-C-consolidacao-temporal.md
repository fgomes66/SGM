# CASO-0012-C — Consolidação Temporal

## Competências

- janeiro de 2022: salário de R$ 3.000,00;
- fevereiro de 2022: salário de R$ 3.000,00;
- março de 2022: salário de R$ 3.300,00.

## Comportamento esperado

O consolidador deve:

- ordenar os resultados cronologicamente;
- preservar os resultados mensais originais;
- somar os subtotais;
- somar os valores finais;
- identificar o período consolidado;
- gerar memória única com referência mensal.

Nesta fase, não há aplicação automática de reajuste salarial.
