# ADR-008 — Aviso-prévio com dias parametrizados

## Status

Aceita.

## Decisão

O aviso-prévio será calculado a partir de uma base explícita, de uma
quantidade de dias e de um divisor mensal informados no plano de cálculo.

## Motivo

A parametrização evita presumir duração, proporcionalidade ou divisor,
preserva decisões judiciais específicas e permite auditoria integral.
