# SGM 0.9.3-A — Estrutura da Aplicação Desktop

## Objetivo

Criar a fundação da interface gráfica Windows sem mover regras de
cálculo para a camada visual.

## Componentes

- `SecaoDesktop`
- `EstadoDesktop`
- `ItemNavegacao`
- `ControladorDesktop`
- `JanelaPrincipal`
- `TelaConteudo`
- inicializador `executar_sgm_desktop.bat`

## Navegação inicial

- Início
- Processo
- Contrato de Trabalho
- Eventos Contratuais
- Cálculo
- Memória de Cálculo
- Relatório Técnico
- Exportação

As telas funcionais serão implementadas nas sub-releases seguintes.
