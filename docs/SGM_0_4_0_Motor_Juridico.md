# SGM 0.4.0 — Fundação do Motor Jurídico

## Objetivo

Representar a cadeia mínima:

```text
Fato
↓
Evidência
↓
Pedido
↓
Comando Judicial
↓
Critério Jurídico Homologado
```

## Regra central

Nenhum critério poderá alimentar cálculo profissional antes de homologação humana.

## Entidades incluídas

- Fato
- Evidência
- Pedido
- ComandoJudicial
- CriterioJuridico

## Próxima evolução

A versão seguinte acrescentará:

- PlanoCalculo;
- vínculo entre critérios;
- verificação de critérios incompletos;
- primeiro caso de uso jurídico.
