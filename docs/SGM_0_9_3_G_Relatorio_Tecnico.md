# SGM 0.9.3-G — Relatório Técnico

A seção Relatório Técnico passa a consolidar:

- identificação processual;
- síntese contratual;
- eventos cronológicos;
- critérios de cada cálculo;
- demonstrativo financeiro;
- memória resumida;
- conclusão técnica;
- rastreabilidade e SHA-256.

O relatório não executa cálculos. Ele reproduz os resultados e memórias
já persistidos no processo.
